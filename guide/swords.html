  • Sword overview

Swords are the close range weapons. They come in a bunch of different varieties. Each sword has a variety of stats and abilities
  • damage: amount of damage done
  • knockback: amount of knockback done to enemies
  • span: how wide the swing is
  • Run Func CD: how often the run function executes
  • Width: width of the sword
  • Height: height of the sword
  • Tier: how many times the weapon has been upgraded
Swords also have two possible abilities which are hidden from players
  • Run func: abilities that execute while the sword is swinging
  • func: abilities that execute on intial swing
