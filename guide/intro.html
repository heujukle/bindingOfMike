Welcome To ____ Game!

The game is all about moving from room to room, getting stronger items and stats with the goal to progress to farther rooms. It is designed to be challenging, so do not be discouraged if you fail!

Tour of starting menu!

When starting the game you will be greeted with the starting menu. It contains a lot of important information to know about!

  • The top of the screen is a textbox, enter your name!
  • Play: Will start the game! good luck!
  • Load game: will bring you to the load save page, read more
  • Change Keybinds: allows you to change the games controls, or view the defaults, read more
  • Guide: opens the guide
  • Leaderboard: opens the leaderboard

The load Save screen

____ supports game saving! In game there will be a save game button in your inventory. (examples in the gameplay section). Saves are downloaded on to your local computer in a JSON file. Simply upload the JSON file to the top box, then press the load save button to continue from where you left off!

Controls /keybind mapping

  • Click: use hotbar item
  • Scroll: change hotbar item
  • w: up
  • a: left
  • s: down
  • d: right
  • e: interact
  • q: inventory
  • m: map
  • l: unstuck
  • double tap w,a,s,d: to dash in those respective directions

Everyone plays games differently, therefor controls sometimes have to be changed. All keyboard inputs are allowed to be remapped to other keyboard inputs. The mouse click and scroll can not be rebound. To remap a key click on the key you want to change then enter the new key. It should update on the menu. Save changes at the bottom and the key will be updates when you start the game.

(controls are case sensitive M is different to m)
